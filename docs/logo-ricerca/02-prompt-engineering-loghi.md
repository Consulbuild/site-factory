# Come si scrive un prompt efficace per un logo professionale (text-to-image 2025-2026)

Rapporto di ricerca (agente, 2026-09-08). Fonti: documentazione ufficiale (OpenAI Cookbook, BFL docs + repo skills, Ideogram docs, Google AI/DeepMind, Recraft docs/blog, Midjourney docs), guide indipendenti, articoli di designer, un repo GitHub di prompt, model card Hugging Face, un forum Adobe, confronti fal.ai. **Reddit non è raggiungibile** dagli strumenti di ricerca/fetch: nessun thread r/… è citato; al suo posto altre fonti community (GitHub, Substack, forum Adobe, HF, PromptHero). Ogni affermazione è seguita dalla fonte.

## 1. Struttura, peso degli elementi e lunghezza

**Prosa naturale, ordinata per priorità: tutti i modelli 2025-26 convergono.**

- **FLUX.2** (BFL): formula «Subject + Action + Style + Context»; «Word order matters — FLUX.2 pays more attention to what comes first»; priorità «Main subject → Key action → Critical style → Essential context → Secondary details». Lunghezze: 10-30 parole per esplorare, **30-80 «usually ideal for most projects»**, 80+ per scene complesse. https://docs.bfl.ai/guides/prompting_guide_flux2 — Il repo ufficiale skills ribadisce: «Use natural language. Prose beats keyword lists», «Quote text», «Hex colors». https://github.com/black-forest-labs/skills
- **GPT Image 1.5/2** (OpenAI Cookbook): ordine «background/scene → subject → key details → constraints»; «For complex requests, use short labeled segments or line breaks instead of one long paragraph»; «Start with a clean base prompt, then refine with small, single-change follow-ups». https://developers.openai.com/cookbook/examples/multimodal/image-gen-1.5-prompting_guide — Il cookbook generale ammette che «Minimal prompts, descriptive paragraphs, JSON-like structures, instruction-style prompts, and tag-based prompts can all work well», ma per la produzione consiglia «a skimmable template over clever prompt syntax». https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide — fal.ai per GPT Image 2: «Scene, subject, specific details, intended artifact, constraints, in that order»; «Avoid vague praise» (niente «stunning», «epic»). https://fal.ai/learn/tools/prompting-gpt-image-2
- **Gemini / Nano Banana**: «Describe the scene, don't just list keywords». https://developers.googleblog.com/en/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/ — Elementi: Subject, Composition, Action, Location, Style + «Clearly state what text should appear and how it should look». https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/
- **Ideogram**: «responds better to natural, sentence-style prompting»; prompt fino a «approximately 150-160 words (around 200 tokens)»; «Longer prompts can give you more control and precision, but only if they're well structured»; struttura «[Image summary]. [Main subject details], [Pose or action], [Secondary elements], [Setting & Background], …»; «Position Text Early in the Prompt». https://docs.ideogram.ai/llms-full.txt — Magic Prompt (LLM interno) espande prompt brevi; modalità Auto/On/Off. https://docs.ideogram.ai/using-ideogram/generation-settings/magic-prompt
- **Recraft V4**: «Short prompts → model designs with you. Long prompts → model executes your architecture»; «Elements placed earlier in the prompt receive higher priority»; «Avoid stacking dramatic or evaluative adjectives». https://www.recraft.ai/docs/prompt-engineering-guide/prompting-with-recraft-v4
- **Midjourney**: «Short and simple prompts typically generate the best images»; la potenza sta nei parametri (`--ar`, `--s`, `--style raw`, `--no`). https://docs.midjourney.com/hc/en-us/articles/32023408776205-Prompt-Basics

**Peso degli elementi per i loghi (community).** Sei decisioni prima di scrivere: tipo di logo, linguaggio di stile, **un solo concetto**, colori nominati, sfondo/formato, esclusioni. https://marketprompter.com/blog/ai-prompts-logo-design — Formula «subject + style + color palette + vibe + technical constraints», **15-30 parole**. https://www.manypixels.co/blog/brand-design/best-ai-logo-prompts — Template «[Style cue] [structure keyword] for [brand context], [color palette], [format modifiers]». https://www.designrush.com/best-designs/logo/trends/logo-design-prompts — Per un'icona: «the prompt should mostly be used to define the shape and style. Only use a few words to describe the subject itself». https://adamlyttleapps.substack.com/p/how-to-create-app-icons-with-a-simple

**Sintesi**: 30-80 parole di prosa, soggetto+tipo di logo in testa, stile, colori (hex dove supportato), testo tra virgolette, sfondo, vincoli in coda.

## 2. Testo integrato scritto correttamente

- **Virgolette ovunque.** Ideogram: «Use quotation marks around the desired text»; «The longer the text… the higher the chance of spelling errors, distortions, or incomplete words»; «most accurate in English»; font descritti a parole («bold sans-serif», «thin rounded bauhaus style»), mai nomi di typeface; se sbaglia: rigenera, usa sinonimi più corti, correggi con l'Editor. https://docs.ideogram.ai/using-ideogram/getting-started/prompting-guide/2-prompting-fundamentals/text-and-typography.md — Guida terza: «Keep quoted text to 6 words or fewer per string»; Magic Prompt «can sometimes rewrite your quoted text» → spegnerlo per lavori di testo. https://www.imagetoprompt.dev/blog/ideogram-prompt-guide/
- **GPT Image**: «Put literal text in quotes or ALL CAPS and specify typography details (font style, size, color, placement) as constraints»; «For tricky words (brand names, uncommon spellings), spell them out letter-by-letter»; «demand verbatim rendering (no extra characters)»; `quality` medium/high per testo piccolo. https://developers.openai.com/cookbook/examples/multimodal/image-gen-1.5-prompting_guide
- **FLUX.2**: «The text 'OPEN' appears in red neon letters above the door»; posizione relativa, stile, dimensione, colore hex («The logo text 'ACME' in color #FF5733»). https://docs.bfl.ai/guides/prompting_guide_flux2 — Variante `flux-2-flex` «Specialized for typography»; la stessa parola può cambiare grafia tra generazioni se non si disabilita il prompt upsampling (`disable_pup` / `prompt_upsampling: false`); «Keep text short». https://prompt-architects.com/blog/468-text-rendering-in-flux-2-what-works-what-doesnt
- **Midjourney**: solo **doppi apici** («single quotes won't work»); alfabeto latino; parole brevi; aiutano «with the words», «text», «written»; se fallisce: `--style raw`, abbassare `--stylize`, Editor/Vary Region; V6+. https://docs.midjourney.com/hc/en-us/articles/32502277092109-Text-Generation — Chi misura: Ideogram «90-95% accuracy versus about 30-40% for Midjourney» (v7). https://prompt-architects.com/blog/34-ideogram-vs-midjourney
- **Recraft V4**: «handles text better than most generative systems, especially when you describe hierarchy»; «Define the typographic system — not just the phrase». https://www.recraft.ai/blog/prompt-engineering-guide
- **Chi fallisce e come si mitiga.** Caso reale ChatGPT: «RETAINED» → «RETAITED», «Good» → «Goood», peggiorando a ogni correzione. https://kristabradford.substack.com/p/chatgpt-text-hallucinations-on-images — Forum Adobe: «Generative AI does not understand words, only letter shapes» → inserire il testo in Illustrator/Express; «saying 'do not add text' it will read 'add text'». https://community.adobe.com/t5/adobe-firefly-discussions/p-text-and-symbol-generation-in-images/m-p/15194421 — Nano Banana 2 «can still struggle with… accurate spelling». https://deepmind.google/models/gemini-image/flash/ — **Mitigazione più citata**: generare solo il simbolo con «no text» e comporre il wordmark in un tool di design. https://www.manypixels.co/blog/brand-design/best-ai-logo-prompts ; https://aituts.com/how-to-create-actual-ai-generated-logos/ ; https://www.mindstudio.ai/blog/recraft-v4-1-brand-design-logos-svg-assets

## 3. Ottenere «flat vector, 2-3 colori, logo» e non illustrazione/mockup

**Parole che funzionano** — OpenAI (esempio ufficiale): «clean, vector-like shapes, a strong silhouette, and balanced negative space… Flat design, minimal strokes, no gradients unless essential… Plain background. Deliver a single centered logo with generous padding. No watermark». https://developers.openai.com/cookbook/examples/multimodal/image-gen-1.5-prompting_guide — Recraft: «Flat colors only — no gradients, shadows, or texture»; «Avoid texture or material-focused language. Vector output responds to structural definition and geometric clarity»; specificare «Line discipline (consistent stroke)», «Layout structure (centered, grid-based, scalable)». https://www.recraft.ai/docs/prompt-engineering-guide/prompting-with-recraft-v4 — Community: «flat vector logo», «simple geometric shapes», «solid colors», «clean lines». https://marketprompter.com/blog/ai-prompts-logo-design — «vector, flat, minimal, simple, geometric», «white background». https://aituts.com/how-to-create-actual-ai-generated-logos/ — «minimalist, vector art, clean lines, flat design, centered composition, isolated on white». https://www.designrush.com/best-designs/logo/trends/logo-design-prompts — Anche le LoRA FLUX community usano «simple flat vector art, isolated on white bg». https://huggingface.co/renderartist/simplevectorflux/blob/main/README.md

**Parole che rovinano** — «Realistic, photorealistic, detailed, shading». https://aituts.com/how-to-create-actual-ai-generated-logos/ — Termini fotorealistici «undermine logo scalability». https://www.designrush.com/best-designs/logo/trends/logo-design-prompts — «Every word here is an opinion. 'Modern,' 'professional,' and 'high quality' mean nothing to an image model». https://marketprompter.com/blog/ai-prompts-logo-design — Per Recraft: texture, grana, materiali, «in the style of». https://www.recraft.ai/docs/prompt-engineering-guide/prompting-with-recraft-v4

**Il problema mockup/sfondo.** Rimedi documentati: chiedere esplicitamente «an isolated subject on a fully transparent background, with no scenery, solid backdrop, checkerboard, or unwanted shadows» (GPT Image, `background="transparent"` PNG/WebP). https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide — «solid background» per eliminare distrazioni. https://www.banani.co/blog/best-midjourney-logo-prompts — Midjourney: «without any fruit» nel prompt **non funziona**, serve `--no fruit`; ogni parola del `--no` è letta separatamente. https://docs.midjourney.com/hc/en-us/articles/32173351982093-No — FLUX.2 «does not support negative prompts. Focus on describing what you want». https://docs.bfl.ai/guides/prompting_guide_flux2 — Gemini: «semantic negatives» (descrivere lo stato desiderato). https://developers.googleblog.com/en/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/ — In FLUX/Gemini quindi «flat solid white background, single centered mark» invece di «no mockup».

## 4. Quanto spazio lasciare al modello

- Recraft esplicita il trade-off: prompt brevi = «interpretive behavior», strutturati = «intentional, controllable, and repeatable». https://www.recraft.ai/docs/prompt-engineering-guide/prompting-with-recraft-v4
- «The biggest mistake I see people make is trying to describe the icon subject in too much detail. This seems to confuse MidJourney». https://adamlyttleapps.substack.com/p/how-to-create-app-icons-with-a-simple — «Simple prompts do better». https://aituts.com/how-to-create-actual-ai-generated-logos/ — Prompt troppo complessi «can confuse the tool and result in a cluttered or inconsistent design». https://www.superside.com/blog/ai-prompts-logo-design
- Ma il vago fallisce: **debole** «Modern minimalist logo for a coffee shop, professional, high quality.» vs **forte** «Flat vector logo mark for a coffee shop: a single coffee bean formed by two interlocking crescent shapes, simple geometric construction, deep espresso brown and cream, isolated on a plain white background, centered, no text, no gradients, no 3D effects, no shadows.» https://marketprompter.com/blog/ai-prompts-logo-design
- Fallimenti concreti: logo basato su lettere in Midjourney «a failed experiment» («the AI always struggles… how the letters are to be arranged and how many to use»). https://weirdwonderfulai.art/general/logo-design-with-midjourney-ai-create-logo/ — e il caso «The Good Search» sopra.
- Regola pratica: fissare **un** concetto, stile, colori, sfondo, vincoli; lasciare libero il *come* (costruzione della forma). Generare 6-10 varianti «like initial designer sketches», tenerne 2-3. https://www.mindstudio.ai/blog/recraft-v4-1-brand-design-logos-svg-assets

## 5. Tecniche avanzate

- **Reference/style**: Ideogram «Upload up to 3 reference images», Style Code riutilizzabile. https://ideogram.ai/models/3.0/ — Gemini 3.1 Flash Image: fino a 3 style reference, 10 oggetti, 4 personaggi. https://ai.google.dev/gemini-api/docs/image-generation — FLUX.2: fino a 8 ref via API; «Clearly describe the role of each: subject from image 1, style from image 2». https://docs.bfl.ai/guides/prompting_guide_flux2 — GPT Image: fino a 16 ref «labeled by role». https://fal.ai/learn/tools/prompting-gpt-image-2 — Midjourney `--sref`. https://docs.midjourney.com/hc/en-us/articles/32180011136653-Style-Reference
- **Seed**: Midjourney, stesso `--seed` → immagini «nearly identical» (v4-6). https://weam.ai/blog/imageprompt/how-to-use-seed-in-midjourney/ — Recraft: riusare il seed del primo risultato buono + blocco di stile di ~20 parole incollato verbatim riduce il drift. https://www.mindstudio.ai/blog/recraft-v4-1-brand-design-logos-svg-assets — Ideogram JSON: «Two runs from the same JSON prompt stay close». https://docs.ideogram.ai/using-ideogram/getting-started/prompting-guide/4.-json-prompting-ideogram-4.0
- **Layout deterministico**: Ideogram 4 JSON con bounding box 0-1000, «up to 16 hex colors», ogni testo come elemento proprio. https://docs.ideogram.ai/using-ideogram/getting-started/prompting-guide/4.-json-prompting-ideogram-4.0
- **Editing iterativo**: GPT Image «change only X + keep everything else the same», «repeat the preserve list on each iteration». https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide — FLUX Kontext: «Replace '[original text]' with '[new text]'» + «while maintaining the same font style and color», una modifica per volta. https://help.nightcafe.studio/portal/en/kb/articles/usage-guide-flux-1-kontext-image-editing ; https://www.mimicpc.com/learn/flux-kontext-prompt-guide-how-to-edit-images — Gemini: «Keep everything the same, but change…». https://developers.googleblog.com/en/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/
- **Lingua**: prompt in **inglese**; il testo quotato può essere italiano (alfabeto latino) ma breve. Ideogram: «most accurate in English»; Magic Prompt «translates and enhances» lingue native. https://docs.ideogram.ai/using-ideogram/generation-settings/magic-prompt — Midjourney: «standard Latin alphabet». https://docs.midjourney.com/hc/en-us/articles/32502277092109-Text-Generation — Ricerca: «significant performance degradation when using languages other than English». https://arxiv.org/abs/2208.09333
- **Negativi**: supportati in Midjourney (`--no`) e Stable Diffusion (template «a logo of {industry}, {objects}, {colors}, modern, minimalism, vector art, 2d, centered» + negative «text, watermark, asymmetric»). https://weam.ai/blog/imageprompt/stable-diffusion-prompts-for-logos/ — Non in FLUX.2 né Firefly; GPT Image accetta esclusioni in prosa («no watermark», «no extra text»). https://developers.openai.com/cookbook/examples/multimodal/image-gen-1.5-prompting_guide

## Template di prompt per logo (derivati dalle evidenze)

**A — Breve (~40 parole, solo simbolo, per FLUX.2/Recraft/GPT Image)**
> Flat vector logo mark for [settore] business: a single [oggetto] built from [2-3 forme geometriche], bold consistent stroke, [colore 1 #hex] and [colore 2 #hex] only, centered on a plain white background, generous padding, no text, no gradients, no shadows, no 3D.

**B — Medio (~80 parole, con wordmark, per GPT Image/Ideogram/Recraft raster)**
> Create an original combination-mark logo for "[NOME]", a local [settore] company in Italy. Mark: [un concetto in una frase], clean vector-like shapes, strong silhouette, balanced negative space. Below the mark the text "[NOME]" in a bold geometric sans-serif, all caps, tight tracking; render the text verbatim, no extra characters. Palette: [colore] (#hex) and [colore] (#hex) on flat white, solid fills only. Single centered logo, isolated, plain background, no mockup, no gradients, no shadows, no watermark.

**C — Midjourney (parametri al posto della prosa)**
> flat vector logo of [soggetto], minimal geometric, [colore] on white background, by [designer di riferimento] --style raw --s 50 --ar 1:1 --no realistic photo detail shading gradient text

(Le basi: struttura/esclusioni OpenAI Cookbook; hex e prosa BFL; «no text» + vincoli Recraft; `--style raw`/`--s`/`--no` Midjourney docs + aituts.)
